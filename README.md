**Silicon Valley Downloader**

A media downloader for YouTube/Soundcloud videos and audio. Downloads MP4 videos or MP3 audio with timecode clipping.

**Note:** Antivirus may flag this as a "trojan" - this is a false positive! It gets detected because it uses legitimate download tools (yt-dlp/FFmpeg) that security software often mistakes for threats. The app is completely safe to use.
